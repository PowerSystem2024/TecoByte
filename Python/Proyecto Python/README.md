# Calculadora de Materiales para Construcción

Este proyecto es una calculadora de materiales de construcción desarrollada en Python. Permite calcular de manera sencilla la cantidad de materiales necesarios para diferentes elementos de una obra, como muros, vigas, columnas, contrapisos, techos, pisos, pintura e iluminación.

## ¿Qué puedes calcular?

- **Muro de ladrillos**: Superficie, cantidad de ladrillos, cemento y arena.
- **Viga de hormigón**: Cemento, arena, piedra y hierro.
- **Columnas de hormigón**: Cemento, arena, piedra y hierro.
- **Contrapisos**: Cemento, arena y piedra.
- **Techo**: Cemento, arena, piedra y hierro.
- **Pisos**: Cemento, arena y piedra.
- **Pintura**: Litros de pintura necesarios para una pared.
- **Iluminación**: Lúmenes necesarios para un área.

## ¿Cómo usarlo?

1. Ejecuta el archivo `Proyecto Python.py` con Python 3:
   ```bash
   python "Proyecto Python.py"
   ```
2. Selecciona la opción deseada del menú ingresando el número correspondiente.
3. Ingresa los datos solicitados por el programa.
4. El programa mostrará los materiales necesarios para la opción elegida.
5. Puedes realizar varios cálculos y ver un resumen total antes de salir.

## Requisitos

- Python 3.x
- No requiere librerías externas
